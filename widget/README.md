# 폰 위젯 만들기 📱

웹앱이라 진짜 위젯은 폰 기능을 빌려야 해요. **D-day + 사진** 위젯을 만드는 법.

---

## 🍎 아이폰 — Scriptable 위젯 (D-day + 사진)

1. App Store에서 **Scriptable** 설치 (무료)
2. Scriptable 열고 우측 상단 **＋** → 새 스크립트
3. [`dday-widget-ios.js`](dday-widget-ios.js) 내용을 **전체 복사**해서 붙여넣기
4. 맨 위 설정만 바꾸기:
   - `ANNIVERSARY` = 사귄 날 (이미 `2026-04-11`)
   - `PHOTO_URL` = 배경 사진 주소 (선택 — 아래 "사진 주소 얻는 법")
   - 스크립트 이름을 **우리Dday** 처럼 저장
5. 홈 화면 빈 곳 길게 누르기 → 좌측 상단 **＋** → **Scriptable** 검색 → 작은 위젯 추가
6. 추가된 위젯을 길게 눌러 **위젯 편집** → Script: **우리Dday** 선택 → Run: 그대로
7. 끝! 홈 화면에 **우리 N일 + 사진**이 떠요. 누르면 앱이 열려요.

### 사진 주소(PHOTO_URL) 얻는 법
- Supabase 대시보드 → **Storage → photos** 버킷 → 원하는 사진 클릭 → **Get URL / Copy URL**
- 그 주소(`https://....supabase.co/storage/v1/object/public/photos/....`)를 `PHOTO_URL`에 붙여넣기
- (우리 photos 버킷은 공개라 위젯에서 바로 배경으로 떠요)

> 사진을 비워두면 핑크 그라데이션 배경으로 깔끔하게 나와요.

## 🤖 안드로이드 — 앱 아이콘 + 디데이 위젯

### (1) 앱 바로가기 아이콘
- Chrome로 앱 주소(`https://httq9302-svg.github.io/YJMG/`) 열기
- 우측 ⋮ → **홈 화면에 추가** → 아이콘처럼 한 번에 실행

### (2) D-day + 사진 위젯
안드로이드는 웹앱 데이터를 위젯에 직접 못 올려서, **디데이 위젯 앱**으로 만들어요:
1. Play 스토어에서 **"디데이 위젯"** 또는 **"D-Day Widget" / "Days Matter"** 설치
2. 새 D-day 만들기 → 날짜 **2026-04-11**, 제목 **우리**, 배경에 **커플 사진** 선택
3. 홈 화면 길게 누르기 → **위젯** → 그 앱 위젯을 홈에 추가
4. 끝! D-day + 사진이 홈에 떠요.

> 앱 데이터(버킷/일기 등)까지 위젯에 띄우려면 네이티브 앱이 필요해서, 위젯은 D-day+사진 정도가 현실적이에요.
